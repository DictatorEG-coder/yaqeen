# يقين | YAQEEN

تطبيق إسلامي أصيل لنظام Android، يركز على القرآن الكريم والسنة النبوية والأذكار والسنن الموثوقة.

## الرؤية

تقديم تجربة عربية راقية تساعد المستخدم على القراءة والاستماع والتعلم والرجوع إلى المصادر الإسلامية الموثوقة.

## النطاق المعتمد

- القرآن الكريم: المصحف، القراء، التلاوات المرتلة والمجودة، المحافل المتاحة، التفسير، البحث، العلامات والمفضلة.
- مشغل القرآن: الاستماع في الخلفية، مزامنة التلاوة مع الآيات عند توفر توقيت موثوق، التكرار، السرعة، مؤقت النوم واستكمال التشغيل.
- الحفظ والتسميع: تسجيل صوت المستخدم ومراجعة المقاطع المحفوظة.
- التجويد: ألوان الأحكام وشرحها وفق بيانات ومراجعة موثوقة.
- السنة النبوية: صحيح البخاري وصحيح مسلم والبحث والتخريج والشرح بمصادر معتمدة.
- الأذكار والسنن: عداد الأذكار، حديث اليوم، وسنة اليوم، وتنبيهات اختيارية.
- العمل دون إنترنت للمحتوى المسموح تنزيله قانونيًا.

## التقنية

- Kotlin
- Jetpack Compose / Material 3
- Android native (لا WebView ولا واجهات HTML)
- Room للتخزين المحلي
- Media3 للوسائط عند إدخال طبقة التشغيل
- WorkManager/Notifications للتذكيرات المجدولة

## مبادئ المشروع

1. توثيق النصوص الدينية ومصادرها.
2. احترام حقوق تسجيلات القراء والكتب والمواد الصوتية.
3. عدم اختلاق بيانات توقيت الآيات أو نسب التسجيلات.
4. عدم تقديم المخرجات الآلية باعتبارها فتوى أو تصحيحًا قطعيًا للتجويد.
5. تجربة هادئة، عربية، سهلة الوصول، وتعمل جيدًا على الهواتف المتوسطة.

## حالة التطوير

المستودع في مرحلة التأسيس. لا تُعد أي ميزة مكتملة حتى تُنفّذ وتُختبر فعليًا.
