## فحوصات المصحف

- ملف المصدر: `app/src/main/assets/quran-uthmani.txt`.
- المصدر المعلن: Tanzil Quran Text, Uthmani, Version 1.1.
- الرخصة المرفقة في الملف: CC BY 3.0؛ يجب إبقاء النص وإشعار الحقوق دون تعديل.
- فحص بنية الملف عبر Git blob: 6,236 سطر آية، 6,236 مفتاحًا فريدًا، لا أسطر آيات مشوهة ولا مفاتيح مكررة، وجميع السور الـ114 لها سجل آية أولى.
- يجب عدم الخلط بين سلامة البنية وبين مراجعة مطابقة النص حرفيًا لمصحف معتمد.
- أُضيف تحقق وقت التشغيل من وجود 114 سورة و6,236 آية ومطابقة عدد الآيات القياسي لكل سورة وتسلسل أرقام الآيات، مع التحقق من وجود البسملة في موضعها للمصحف.
- بيانات الملف تضع البسملة في بداية سجل الآية الأولى لمعظم السور (باستثناء الفاتحة والتوبة). منطق العرض يستخرجها من السطر الأصلي نفسه ويفصلها بصريًا دون تعديل ملف المصدر أو تكرارها، مع احترام فروق الرسم بين السور.

## الاختبارات

- اختبار JVM: `QuranAssetIntegrityTest` يقرأ ملف الأصول نفسه، ويستدعي محلل التطبيق الفعلي، ويتحقق من 114 سورة و6,236 آية، وعدد الآيات القياسي لكل سورة، وتسلسل المفاتيح وعدم تكرارها، وحدود البسملة وإشعار المصدر والرخصة.
- اختبار JVM: `QuranAudioSourceTest` يتحقق من روابط المصادر الصوتية الثمانية، وحدود أرقام السور، وتحويل مدة مؤقت النوم، واستعادة رقم السورة عند تبديل القارئ.
- آخر تشغيل تحقق: GitHub Actions run `45474842861` على commit `9e328c6198803a5c7b72ef27d05fed88bd3078ab`؛ نجح بناء Debug APK واختبارات `testDebugUnitTest`، ورُفع artifact باسم `yaqeen-debug-apk`.
- اجتازت اختبارات المصحف ومصادر القراء الثمانية ومدد مؤقت النوم واستعادة السورة عند تبديل القارئ. لا يعني نجاحها أن الصوت اختُبر فعليًا على هاتف أو أن كل رابط صوتي تم تشغيله.
- هذه اختبارات بنية ومحلل بيانات؛ لا تثبت وحدها المطابقة الحرفية لكل آية مع مصحف مطبوع، ولا تغني عن اختبار الواجهة والصوت على هاتف فعلي.

## الاعتماديات والخدمات الخارجية

- Media3 1.9.4 مدمج لتشغيل المنشاوي المرتل في الخلفية. Room وWorkManager لم يُدمجا بعد؛ العلامات وموضع القراءة حاليًا في SharedPreferences.
- البث المباشر لملفات المنشاوي المرتل يستخدم روابط QuranicAudio مباشرة مع إظهار النسبة للمصدر. أما بيانات التلاوات والتوقيت والمحتوى عبر Quran Foundation API فتتطلب اعتماد OAuth2 من خادم آمن؛ لا يوضع سر العميل داخل تطبيق Android.
- بيانات التوقيت متاحة عبر موارد مستقلة للقارئ والتسجيل، ولا يجوز افتراض تطابق توقيت قارئ مع تسجيل آخر.
- API موقع Sunnah.com يتطلب مفتاح وصول، ويغطي جزءًا من البيانات فقط وفق توثيق المطورين. لا بد من الحصول على الإذن والمفتاح والتحقق من نطاق البيانات قبل الاعتماد عليه.
- لا يجوز إعادة توزيع أو تنزيل أي تسجيل صوتي أو كتاب إلا وفق شروط مصدره.
