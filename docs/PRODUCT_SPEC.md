# مواصفات المنتج — يقين | YAQEEN

## النطاق
تطبيق إسلامي فقط. لا توجد وظائف لتنظيم الحياة اليومية أو المهام أو الإنتاجية.

## التصميم
- فاخر وهادئ.
- أسود عميق، أخضر زمردي، ذهبي هادئ.
- العربية وRTL بالكامل.
- Android أصلي بـ Kotlin وJetpack Compose.
- لا HTML ولا WebView.

## الأقسام
1. الرئيسية.
2. القرآن الكريم.
3. السنة النبوية (صحيح البخاري وصحيح مسلم).
4. الأذكار.
5. السنن المهجورة.
6. المحفوظات والإعدادات.

## القرآن
- القراء: محمد صديق المنشاوي، عبد الباسط عبد الصمد، محمود خليل الحصري، مصطفى إسماعيل، محمود علي البنا، محمد رفعت، عبد الرحمن السديس، سعود الشريم، ماهر المعيقلي، مشاري العفاسي، وغيرهم.
- مرتل ومجود بحسب ما يتوفر لكل قارئ.
- القراءة فقط، الاستماع فقط، القراءة مع الاستماع.
- مزامنة الصوت مع الآيات والكلمات/الحروف عند توفر بيانات توقيت موثوقة.
- التكرار، الحفظ والتسميع، تسجيل الصوت، سرعة التشغيل.
- مساعد التجويد وألوان الأحكام.
- التفسير بمصادره، البحث، العلامات والمفضلة، ختمة اختيارية.
- مكتبة المحافل والتسجيلات.
- مؤقت نوم، استكمال التشغيل، تنزيل دون إنترنت للمحتوى المسموح.

## السنة والأذكار
- صحيح البخاري وصحيح مسلم.
- البحث المتقدم، التخريج، درجة الحديث، الشرح ومصادره.
- الأذكار مع العداد.
- حديث اليوم والسنة المهجورة.
- إشعارات اختيارية قابلة للتخصيص.

## الثوابت
- لا محتوى ديني بلا مصدر.
- لا تسجيلات بلا تحقق من النسبة والحقوق.
- لا بيانات مزامنة مخترعة.
- لا فتوى آلية ولا ادعاء تصحيح تجويد قطعي.
- لا إعلانات مزعجة.
- تقليل جمع البيانات والعمل دون إنترنت حيث أمكن.
